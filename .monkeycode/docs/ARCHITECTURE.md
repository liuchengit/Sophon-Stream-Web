# Sophon-Stream Web 管理系统架构文档

## 系统概述

基于 sophon-stream 流处理框架的边缘 AI 视频分析管理平台，采用控制面与数据面分离架构。

## 模块说明

### 前端层
- **技术栈**：Vue3 + TypeScript + Element Plus + ECharts + Vue Flow
- **职责**：用户界面、数据可视化、用户交互

### 控制面
- **技术栈**：C++17 + Drogon Web 框架
- **职责**：API 服务、业务逻辑、数据持久化、认证授权

### 数据面
- **技术栈**：sophon-stream 流处理框架
- **职责**：视频解码、AI 推理、目标跟踪、结果输出

### 存储层
- **技术栈**：SQLite
- **职责**：配置存储、运行数据、日志记录

## 核心流程

### 任务创建与执行

1. 前端创建任务，提交配置到后端
2. 后端保存任务配置到数据库
3. 用户启动任务，后端调用 GraphManager 创建 Graph 实例
4. GraphManager 配置 sophon-stream Engine 并启动流水线
5. 视频流通过解码器进入处理流水线
6. AI 推理和跟踪结果通过 ResultCollector 收集
7. 结果通过 WebSocket 推送到前端

### 配置热更新

1. 用户提交新配置到后端
2. 后端验证配置格式
3. 创建配置版本记录
4. 调用 Engine.updateConfig() 应用新配置
5. 更新过程中保持现有 Graph 运行
6. 更新失败则回滚到上一版本

## 安全设计

- JWT Token 认证，有效期 2 小时
- RBAC 权限模型，角色-权限-资源三级控制
- 密码 bcrypt 哈希存储
- 操作审计日志
